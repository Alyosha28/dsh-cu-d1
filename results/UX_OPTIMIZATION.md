# 体验优化交付记录

日期：2026-10-31

## 运行控制

- `RunController.pause` 不再中止活动运行。运行状态变为 `paused`，循环在下一个检查点等待 `waitWhilePaused`；`resume` 唤醒同一个运行并继续当前步骤。停止和接管仍然中止运行并保持终态。
- 暂停时间从墙钟预算中扣除（`RunBudget.creditPaused`），长时间暂停不会因为预算耗尽而失败。
- 浏览器与原生控制器在观察、决策、等待批准、动作、等待、验证、暂停、完成、失败等阶段发送活动事件。面板显示阶段、动作、步骤和页面标题。
- 完成、失败、阻断和接管后保留结果卡片；关闭按钮或下一次运行清除结果卡片。
- Browser 启动模式接管时打开带当前 Cookie 与 URL 的有头浏览器；接入模式将现有受控标签页置于前台。原生接管保留目标窗口。

## 审批

- 后果性动作在 D1 选定具体动作后请求批准，提示包含操作、目标名称和应用或页面范围；批准只覆盖当前动作。`allowConsequential` 仍可预先授权整个运行。
- 登录批准在凭据输入或登录按钮点击时触发，仅观察密码字段不再触发。
- 原生多窗口在未指定 `windowId` 时通过 `userQuestions` 提供带窗口标题和窗口标识的选择列表；无法提供选择时返回 `window_selection_required` 和窗口列表。
- Skill 发布审批展示适用范围、风险、步骤数、验证断言数、最新证据和演化来源。

## 权限与启动

- 原生侧同时检查辅助功能与屏幕录制权限。辅助功能缺失返回 `accessibility_permission_required`，截图回退前发现屏幕录制缺失或在截图时遇到权限错误返回 `screen_recording_permission_required`，两者都带恢复说明。
- 控制页提供辅助功能与屏幕录制两行状态，以及打开系统设置或请求权限的入口。
- 指示器辅助程序按源文件内容缓存到私有临时目录，同一构建在多个 Agent 和会话之间复用；编译失败时降级为空指示器，运行继续。
- 非 macOS 平台不再因可见预览直接失败；浏览器退回页面内指示器，控制页仍可用。

## 浏览器观察与目标选择

- 新增 `browser_observe`：返回当前页面的元素编号、角色、名称、值、可用动作、上下文和截断标记，不调用 D1、不派发输入。
- 接入模式新增 `tabUrl` 与 `tabTitle`。未找到或匹配多个标签页时返回 `tab_selection_required`，不再静默控制第一个标签页。
- 预览面板通过每次画面更新同步当前页面标题。

## 模型指引与错误

- 两个 Provider 的指引补充输入语义、结果状态、原因码和恢复步骤。
- 子目标、验证断言、策略、提取字段和原生应用参数增加字段级描述。
- 原生 CUA 工具错误提取 `code` 与 `message`，不再把完整工具结果序列化后抛出。
- 浏览器与原生已知错误返回 `{status, reason, message, recovery}` 结构；未知错误继续抛出。

## 控制页与本地化

- 控制页改为状态卡片、控制按钮、权限行、技能列表和审计时间线，支持删除技能记录。
- 控制网址携带 `#token=` 片段，页面一次性读取后保存到会话存储，不再要求手动粘贴令牌。
- 面板、控制页和审批提示支持 `zh` 与 `en`；模型指引保持英文。`locale` 配置默认中文。
- 控制页状态每秒刷新，失败时保留分区错误并提供连接状态。

## 文档

- `README.md` 更新工具面、可见控制、接管、暂停/继续、标签页选择、本地化和权限行为。
- `SKILL.md` 增加 `browser_observe` 路由，并更新结果卡片与指示器清理规则。
- `ARCHITECTURE_PLAN.md` 更新暂停/继续、单次动作审批和权限引导。

## 接管状态转移（补做）

- 启动模式接管前读取受控页的地址、Session Storage、滚动位置和表单值；Cookie 与 Local Storage 沿用 Playwright `storageState`。
- 新标签页在页面脚本执行前注入 Session Storage，导航完成后再恢复表单值与滚动位置。
- 字段优先按 id、其次按唯一 name 匹配；两者都没有的匿名控件才退回位置匹配，且要求标签与类型一致。页面结构已变化时不会把值写进别的控件。
- 可见接管窗口仍未纳入自动测试；`tests/takeover.spec.ts` 覆盖状态捕获、恢复和结构变化时的拒绝写入。

## 边界

- DSH 客户端内的运行面板尚未接入；当前入口是控制页、macOS 预览面板和原生状态面板。
- 浏览器直接工具面仍限于子目标、观察、提取、控制和发布；Playwright MCP 的标签页、上传下载、对话框和网络工具没有并入同一受控页面。
- 接管时打开的有头浏览器携带 Cookie、Local Storage、Session Storage、滚动位置和已输入的表单值；字段按 id 或唯一 name 匹配，身份消失的控件保持空白。
- 控制页的系统权限按钮打开对应的系统设置页，不直接触发 macOS 权限对话框。
- 面板本地化覆盖中文与英文；其他语言回退到中文。
